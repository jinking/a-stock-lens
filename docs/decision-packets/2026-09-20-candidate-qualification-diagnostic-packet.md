## 三、四大核心因子异象与数据质量深度剖析

实测数据揭示了全市场环境下 4 个典型的因子分布异象，这也是绝对资格门槛（Absolute Qualifiers）必须介入的根本原因（单纯依赖相对百分位排序会直接将异象股票误选入候选池）：

### 1. Growth 极值爆发异象（微利基数引起同比暴增）
- **观测事实：** `net_profit_parent_yoy`（归母净利润同比增速）样本最小值 -7307.61%，中位数 12.81%，**极大值高达 415,612.12%（超 4,100 倍）**！
- **业务机理：** 许多周期股或困境反转股去年同期净利润仅数万元，本期正常盈利数百万元即可造成上万倍的表观增速。纯百分位排名会将 300% 优质可持续增长与 400,000% 的基数异象视作相邻名次。
- **治理建议：** 必须在绝对门槛中同时要求 `net_profit_parent_cagr_3y`（3 年复合增速）或 `revenue_yoy`（营收增速）形成交叉验证，滤除不可持续的爆发点。

### 2. Dividend 支付率失真异象（超额分配与特别分红）
- **观测事实：** `dividend_payout_ttm` 样本中位数为 0.33（33% 正常区间），但**最大值达 92.82（即 9282% 的股息支付率）**！
- **业务机理：** 极高支付率通常来自动用历年留存收益进行的短期清仓式分红、或者重大资产重组后的特别派息。这不仅不可持续，甚至可能损害公司后续运营资本。
- **治理建议：** 绝对门槛必须设置股息支付率的上限（例如不超过 80% 或 100%），或设定 `20% <= payout <= 80%` 的健康可持续区间。

### 3. GARP 策略中源端 PEG 量纲异象
- **观测事实：** 全市场 `peg` 因子共有 957 只可计算（非正值按规则判定为 `NOT_APPLICABLE`），最小值 0.86，**中位数高达 166.27，最大值达 407,402.50**！
- **业务机理：** 上游 Provider (neodata) 的 PEG 指标并非金融学常识中的 `0.5 ~ 2.0` 量纲，其分母增速采用的是绝对百分点还是未换算基数导致整体量纲被放大了 100 倍以上。
- **治理建议：** 在使用源端 PEG 时，绝对门槛不可直接硬编码 `peg <= 1.5`；方案可选择基于当前量纲设定上限，或在后续阶段通过 `pe_ttm / net_profit_parent_cagr_3y` 进行统一标准重构。

### 4. Value 策略的金融蓝筹与高覆盖特征
- **观测事实：** Value 策略 Top 5 全部被大型险企包揽（新华、人寿、人保、太保、平安），行业前三为证券Ⅱ、工业金属、电力。

- **治理建议：** 价值策略需明确是否引入行业中性，或者通过对 ROE 或分红的联合门槛来避免单一行业过度扎堆。
