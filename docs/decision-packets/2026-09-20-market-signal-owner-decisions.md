## 3. 市场环境状态 (Market Regime) 决策方案

### 3.1 现状与输入缺口分析
- **现有可用输入**: 各策略合格标的自身的横截面技术特征（ret_20d, ret_60d, proximity_52w_high, avg_amount_20d）。
- **当前缺失输入**:
  - `benchmark_index_trend`: 宽基基准（沪深300 / 中证500 / 中证1000 / 创业板指）的日线与长短期均线。
  - `market_breadth`: 全市场宽度（如全市场站上 20 日均线股票占比、A股腾落指标 ADL）。
  - `market_volatility`: 宏观波动率（全市场平均真实波幅中位数 ATR、或历史波动率分位数）。

### 3.2 方案选项对比

#### 选项 R1: 基准指数趋势法 (Index-Only Regime)
- **机制**: 仅跟踪中证 800 或沪深 300 指数的均线趋势（如 Index Close > MA20 且 MA20 > MA60 判定为 `BULL`；Index Close < MA20 判定为 `BEAR`；其他为 `RANGE`）。
- **优点**: 输入极简，仅需新增 1 个指数日线行情数据源。
- **缺点**: A股常出现“指数失真”（微盘股流动性危机时大盘蓝筹护盘拉抬指数，或权重股砸盘而小盘活跃），单一指数无法反映真实赚钱效应与市场宽度。

#### 选项 R2: 复合多维市场环境 (Multi-Input Regime) —— **【架构推荐】**
- **机制**: 采用 **三因子投票制**:
  1. **指数趋势 (Index Trend)**: 沪深300 与 中证1000 双均线方向；
  2. **市场宽度 (Market Breadth)**: 全市场股票中收盘价高于 20日均线的比例（`breadth_ratio`）：
     - `breadth_ratio > 55%`: 进攻环境
     - `40% <= breadth_ratio <= 55%`: 震荡分化
     - `breadth_ratio < 40%`: 防守/弱势
  3. **极端波动率 (Volatility Check)**: 避免在宏观流动性踩踏周发布激进信号。
- **优点**: 真实反映 A 股多空生态，杜绝指数虚假繁荣。
- **代价**: 需要在 Provider 层接入指数日线行情及日级别宽度聚合计算。

> **待项目所有者审定 1**:
> - [ ] 确认采用 **选项 R2**（多维复合），并在近期开发计划中排期指数与市场宽度 Provider；
> - [ ] 或在短期过渡阶段先采用 **选项 R1**（单指数轻量判定）。

## 4. 市场验证 (Market Validation) 规则与状态矩阵决策

市场验证的作用是：**在策略完成选股后，从客观市场行为角度验证该股票当前是否适宜跟踪**。
其核心判定输出为三态枚举：
`MarketValidation`: `CONFIRMED`（验证通过）、`NEUTRAL`（中性观察）、`CONTRADICTED`（市场冲突/背离）。

### 4.1 验证维度与阈值提案

结合本次实测分布，提议 5 项验证规则：

| 维度 | 评估指标 | 判定为支撑 (Positive) | 判定为冲突 (Negative) | 实测分布依据 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 个股趋势** | `ret_20d` 与 `proximity_52w_high` | **动量**: ret_20d > P25 (6.4%) 且 proximity > 0.85<br>**价值/红利**: ret_20d > -10%（未破位） | **动量**: ret_20d < 0 或破位大跌<br>**通用**: 20日跌幅超过 -15% (低于 P10) | Momentum 标的普遍在高位，破位即逻辑破坏；Value 允许筑底。 |
| **2. 板块/行业** | 申万一级行业 20日相对超额 | 行业收益率 > 市场基准 | 行业收益率处于全市场后 20% | 规避“行业退潮期”的伪价值陷阱。 |
| **3. 相对强弱** | 标的相对中证全指 60日收益率 | 个股 ret_60d - 指数 ret_60d > 0 | 超额收益严重为负 (< -20%) | 识别真正强势龙头。 |
| **4. 量价配合** | 5日均量 / 20日均量 (`vol_ratio`) | 上涨伴随放量 (`vol_ratio > 1.05`) | 连续缩量阴跌或巨量破位 | 规避无量阴跌。 |
| **5. 流动性底线** | `avg_amount_20d` | `avg_amount_20d >= 1.5 亿元` | `avg_amount_20d < 1.0 亿元` | 今日实测 P10 均大于 1.7 亿元，1.0 亿是极小流动性警戒线。 |

### 4.2 状态判定矩阵 (State Matrix)

- **`CONFIRMED` (通过)**:
  - 流动性底线合格，且满足“个股趋势”支撑，且“负向冲突项数 == 0”。
- **`CONTRADICTED` (冲突)**:
  - 触发流动性警戒线 (`< 1.0 亿`)，或“负向冲突项数 >= 2”（如处于破位下跌 + 板块暴跌）。
- **`NEUTRAL` (中性)**:
  - 介于上述两者之间（如趋势平淡但无严重破位，处于蓄势或弱平衡状态）。

> - [ ] 或调整流动性红线（如要求更高或更低阈值）。

## 5. 信号输入矩阵 (Signal Input Matrix) 决策

在 Market Validation 完成后，Signal 模块为候选股票打上当期交易特征标签（不是买卖指令，而是特征信号）。

### 5.1 候选规则词表与触发逻辑提案

| 策略 | 候选信号类型 | 触发技术条件建议 | 状态释义 |
| :--- | :--- | :--- | :--- |
| **Momentum** | `BREAKOUT` | `proximity_52w_high >= 0.95` (即实测 P75 分位) 且放量 | 向上突破一年新高 |
| **Momentum** | `TREND_CONTINUE` | `ret_20d >= 6.4%` (P25) 且 `proximity_52w_high` 在 0.85 ~ 0.95 之间 | 强趋势稳步上行中 |
| **Momentum** | `PULLBACK` | `ret_60d >= 23.2%` (P50) 但 `ret_20d` 短期在 0% ~ 5% 窄幅休整 | 中期强势股良性技术回踩 |
| **Value / Dividend** | `VALUE_CONTRARIAN` | 估值分位数合格 + 20日收益率企稳 (`ret_20d` 介于 -5% ~ +2%) | 深度低估值区间筑底企稳 |
| **Value / Dividend** | `DIVIDEND_SUPPORT` | 股息率 TTM >= 门槛 + 波动率较低且不创新低 | 高股息红利防御底仓特征 |
| **通用风险信号** | `TREND_WEAKEN` | 曾为强势股，但 20 日跌幅扩大且跌破 20 日均线 | 涨势减弱，需谨慎跟踪 |
| **通用风险信号** | `BREAKDOWN` | 20日跌幅超过 -15% (破位加速下跌) | 破位风险，终止跟踪 |

## 6. Candidate 发布语义决策：Mode A vs Mode B

当前整个生产链路中，由于 Dividend 分红历史数据仍在进行历史缺口补抓（需等待项目所有者对 Plan B 决策回执的最终确认），且 Market Regime / Validation 处于待审批状态。
关于 Candidate 生成与发布的行为语义，存在两种架构路线：

### 选项对比分析：

```mermaid
flowchart TD
    subgraph Mode A [Mode A: 策略级独立就绪 (Per-Strategy Release)]
        A1[Momentum / Value / Growth 策略] -->|验证规则就绪| A2[发布对应策略 Candidate]
        A3[Dividend 策略] -->|分红数据补齐中| A4[保持 BLOCKED / 无 Candidate]
    end

    subgraph Mode B [Mode B: 全系统统一步伐 (Global Release - 当前基线)]
        B1[全策略: 动量 / 价值 / 成长 / 红利]
        B2[全套市场环境与市场验证]
        B1 & B2 -->|全部完备且所有者签署| B3[统一解开日常管道 BLOCKED_REASONS]
        B1 -.任一部分未完备.-> B4[全局安全阻断 Fail-Closed]
    end
```

| 维度 | Mode A (按策略单轨发布) | Mode B (全系统全局阻塞，当前基线) |
| :--- | :--- | :--- |
| **核心逻辑** | 策略间解耦：哪个策略的数据与验证完备，就允许哪个策略独立产出 Candidate。 | 系统级一致：必须全系统核心策略、市场验证规则全部通过审批后，统一步伐解除日常管道阻断。 |
| **优点** | 灵活性高，Momentum、Value 等数据已完备的策略可以先行进入前端测试与日常追踪。 | 严谨性高，杜绝半成品输出；确保全系统多因子和策略在统一的视角和基准下进行横向对比与风控。 |
| **潜在风险** | 前端与下游用户可能看到“只有部分策略有股票”，产生策略遗漏的误解；且状态管理复杂度上升。 | 需要等待分红事件与宏观市场数据全部闭环，业务端看到完整 Candidate 的周期稍长。 |
| **【架构推荐】** | **阶段性推荐**: 如果所有者希望快速体验端到端 Candidate 产出，可批准 Mode A。 | **生产级推荐**: 作为严谨的严肃投研辅助系统，推荐坚守 **Mode B**，直至全链路完整验收。 |

> **待项目所有者审定 4**:
> - [ ] **选择 Mode B** (坚持全局阻塞，待全链路规则与数据完备后统一发布)；
> - [ ] 或 **选择 Mode A** (授权完备策略先行发布，未完备策略独立保持阻断)。

## 7. 真实边界样本案例透视 (Representative Case Sampling)

基于今日真实运行采集的代表性极值样本，其在不同规则下的模拟表现如下：

1. **极端动量突破样本 (`300741.SZ` - 华宝新能)**:
   - `ret_20d`: **+99.19%** (策略合格池最高)
   - `proximity_52w_high`: **1.0000** (触及 52 周最高价)
   - `avg_amount_20d`: **4.0 亿元**
   - **透视**: 该标的处于极强的主升浪行情。在 Market Validation 中将轻松获得 `CONFIRMED`；在 Signal 中将触发 `BREAKOUT`。但若市场环境（Regime）判定为极弱势震荡，系统需要审定是否对高位连板标的进行过热提示。
2. **动量合格但短期横盘样本 (`300434.SZ` - 金石亚药)**:
   - `ret_20d`: **+0.56%** (策略合格池最低)
   - `proximity_52w_high`: **0.8845**
   - **透视**: 该标的过去中期涨幅满足动量门槛，但近 20 日几乎横盘滞涨。在 Validation 中若采用纯 20 日绝对涨幅，可能落入 `NEUTRAL`；若按良性回踩判定，可能触发 `PULLBACK` 信号。
3. **成长策略重挫样本 (`688525.SH` - 佰维存储)**:
   - `ret_60d`: **-56.55%**
   - `proximity_52w_high`: **0.5123** (距离一年高点折价近半)
   - **透视**: 虽财务成长指标达标，但近 3 个月股价腰斩。在 Market Validation 中应当明确触发 `CONTRADICTED`（个股趋势严重恶化），有效阻断其直接进入候选买入视线，体现市场验证的安全垫价值。
4. **流动性边界样本 (`000526.SZ` - 学大教育)**:
   - `avg_amount_20d`: **1.508 亿元**
   - **透视**: 恰好落在流动性底线建议值（1.5 亿）边缘。若成交量进一步萎缩至 1.0 亿以下，系统应自动发出流动性预警并降级为 `NEUTRAL` 或 `CONTRADICTED`。
