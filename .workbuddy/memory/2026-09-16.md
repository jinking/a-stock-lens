## 本片的关键裁决（后续切片需要遵守）

1. **不实现策略评分**：`score` / `rank_percentile` / `confidence` 保持 `null`，直到权重评审通过。
2. **`next_action` 恒为 `IGNORE`**：设计枚举了动作但没定义选择规则，`IGNORE` 是唯一不误导的默认值。
3. **快照是 JSON 不是 DuckDB**：`SnapshotStore` 协议先定，DuckDB 实现后续按同一协议替换。
4. **窗口不完整即 `NULL`**：不用更短的窗口凑均值。
5. **因子窗口无代码默认值**：必须来自 `configs/factors/*.yaml`。
6. **质量门禁只报告不修复**：单条坏数据 P2 不阻断扫描；整个数据集为空才是 P1。无比例阈值。

- **`tmp_path` 不可用**：沙箱拒绝往系统临时根 `mkdir`。已加 `tests/conftest.py` 的 `local_tmp` fixture
