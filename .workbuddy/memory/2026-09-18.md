## 三、Task 1：研究池前置筛选边界（提交见下）

- 新增 `src/astock_lens/universe/prefilter.py`：`PrefilterResult`（`included` / `excluded`）
  与 `prefilter_listing(securities, *, config, as_of)`。
- **边界裁决**：前置筛选只判定上市元数据可回答的规则——交易所、ST、退市板块、上市年龄；
  明确**不**判定流动性、当日是否有行情、停牌天数、以及任何策略分数。缺行情/缺流动性度量的

  （`exchange_exclusion` / `st_exclusion` / `delisting_board_exclusion` /
  `long_suspension_exclusion` / `short_listing_exclusion`），`BUILDER_RULE_CHECKS` 固定顺序；
  前置筛选按 `LISTING_RULE_CHECKS` 复用其中四条。两条一致性测试（逐规则判定相同、
  与 builder 在真实 fixture 上清单判定完全一致）就是"不许长第二份语义"的守门人。
- `_require_timezone` 提升为公开的 `require_timezone`，供前置筛选复用，避免出现第三份弱守卫。
- 顺序保持：快照里排除项的产出顺序仍是 EXCHANGE → ST → DELISTING_BOARD → LONG_SUSPENSION →
